# Cypress Login Tests

Projeto de automação de testes de login utilizando **Cypress**, desenvolvido como parte de estudos práticos em **QA Automation**.

## 🎯 Objetivo

Validar o comportamento da funcionalidade de login em diferentes cenários, simulando situações encontradas em testes de software.

## 🧪 Cenários testados

* ✅ Login com credenciais válidas
* ❌ Login com credenciais inválidas
* 🔎 Validação do redirecionamento após login
* 🔎 Validação de mensagens e comportamento da aplicação

## 🛠️ Tecnologias

* JavaScript
* Cypress
* Node.js
* Git
* GitHub

## 🚀 Como executar

Clone o projeto:

```bash
git clone https://github.com/codemaciel/cypress-login-tests.git
```

Entre na pasta:

```bash
cd cypress-login-tests
```

Instale as dependências:

```bash
npm install
```

Abra o Cypress:

```bash
npx cypress open
```

Selecione **E2E Testing** e execute o arquivo de testes de login.
